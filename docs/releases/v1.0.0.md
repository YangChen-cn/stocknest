# StockNest v1.0.0

StockNest 1.0 将轻量美股持仓追踪扩展为更方便的个人报告工具：报告计划可调节、数据更可靠，并能直接把结构化信息交给 AI 分析。继续使用与私人版 StockWatch 相同的核心代码，不连接券商、不自动交易。

以下为相对 v0.1.0 的更新。

## 报告与自动化

- 在 Dashboard 设置中分别开启或关闭盘中简报、收盘日报、周报和月报，并调节发送时间。
- 盘中与收盘报告可选择周一至周五的发送日，默认美东时间 10:23 / 18:53，支持夏令时。
- 新增可选周报、月报，默认关闭。周报每周六发送；月报在新月第一个周末日发送，默认香港时间 10:52。使用已完成交易日的数据，汇总期间收益、基准对比、资金流、盈亏和手续费。
- 支持 cron-job.org 外部触发，并通过 Dashboard 同步配置、调用云端任务更新外部计划。GitHub 原生调度保留为后备方案。
- 在安装 OpenBB 前检查报告开关、日期与已发送状态，减少无效任务开销。各报告独立去重，周期报告不会消费日报提醒。

## 更适合 AI 分析的邮件

- 邮件附带版本化 JSON 数据附件，同时保留正文中的结构化数据块，方便 Gmail 连接器或 AI 读取。
- Dashboard 与观察列表可一键导出当前 AI 数据，无需等待邮件。
- 数据包含持仓、行情日期、历史表现、提醒及数据完整性信息；已填写的持仓逻辑也会显示在邮件中，空白时省略。
- 盘中正文仅突出涨跌幅绝对值达到 5% 的纯观察股票，最多三只；其余观察信息保留在 AI 数据中，目标价接近提示及已触发提醒继续单独展示。

## 行情可靠性与加载体验

- 收盘数据不完整时，最多检查三次，默认每次间隔两分钟。拿到完整数据后才发送正常日报；持续失败则发送一次报错通知，不提前消费提醒。
- 已完成交易日的行情使用本地缓存；新交易日收盘或手动刷新时更新，减少闭市期间重复查询。
- 改善股票搜索、选择后的行情预览、持仓逻辑编辑与观察列表交互。
- 持仓备注、可选本机 Gmail 和高级自动化控件默认折叠；总览增加独立的可选观察股票图表，并隐藏 Streamlit 部署入口。

## 可选 HSBC 成交导入

- 通过只读 Gmail IMAP 识别格式明确、确认完成的 HSBC 美股成交，并按交易编号去重。
- 支持 Dashboard 手动同步和报告前自动同步；日常只检查最近三天，手动历史补录可选择更长范围。
- 未知格式、部分成交、取消或解析失败的邮件跳过并记录日志。自动导入默认关闭，需要用户自行配置。

## 升级与配置

- 内部 Python 包名和命令继续为 `stockwatch`，现有持仓、配置与提醒状态兼容。
- 周报/月报需自行开启；修改本地计划后，使用“同步并应用云端计划”更新 cron-job.org，单纯保存配置不会改变外部触发时间。
- 云端 Gmail Secrets 与可选本机 Gmail 配置明确分开。本机未配置不会影响云端邮件。
- 更新 Dashboard 代码后请重启后台服务，浏览器刷新不会保证卸载已导入的旧模块。
- 公开仓库保留 Demo 与示例配置，个人数据和 Secrets 默认忽略；请创建私人副本运行个人自动报告。维护用 AGENTS.md 保留在本地，不再跟踪提交。

## 验证与限制

发布前的功能回归基线为 245 项离线测试，另包含依赖兼容性、无 Dashboard 依赖的日报预览与公开文件/历史扫描。公开仓库 CI 继续验证运行环境。

仍为仅追踪持仓的日频近似：不包含现金账户、自动股息、税务或自动公司行动处理，基准采用价格回报。免费行情可能延迟或缺失，外部触发也不能保证精确投递；cron-job.org 触发仍消耗私人 GitHub Actions 额度。HSBC 导入仅适用于明确支持的邮件格式，应核对导入结果。

安装、Gmail、Demo 与自动化配置见 [README](../../README.md) 和中文使用说明。
