# StockNest v1.1.0

> 一份好的持仓记录，应当像一页写得工整的日记：数字诚实，版面干净，不管今天是否值得庆祝，它都在。

StockNest 1.1 是一次关于「呈现」与「交付」的版本：邮件与面板全部重新排印，涨跌有了颜色，新高有了仪式感；同时，它第一次走出了你的电脑——云端只读页面让持仓在合上笔记本之后仍被安静地注视；而报告的触发权，也以一个明确的开关交还给你。依旧不连接券商、不自动交易、只陈述事实。

以下为相对 v1.0.0 的更新。

## 一封重新排印的信

- 邮件整体重构：品牌色头带与每日一句题词开场，市值与当日盈亏以大字号呈现——赚了是绿色，亏了是红色，一眼即明。
- 报告正文改为结构化卡片：投资表现是端正的对齐表（成立以来、基准、超额收益、已实现盈亏），持仓与观察列表是带分隔线的清单，告警独立成卡。信息密度更高，字却不再挤作一团。
- 纯文本版与 JSON 数据附件的结构保持不变：旧的解析方式照常工作，变的只是外衣。
- 面板与邮件共用同一套暖色版式与原创短句；短句按日轮换，中英对应，只谈耐心与记录，不谈涨跌预言。

## 里程碑，只认完整的历史

- 组合净值创出新高时，面板与收盘邮件会郑重地写下一句「创历史新高」；其余日子，则安静地告诉你距离上一个高点还有多远。
- 这句祝贺来之不易：它要求完整、连续的净值历史；盘中只是估算，会如实标注；数据缺失的日子，宁可沉默，绝不虚报。
- 总览指标加上红绿箭头，持仓表与收益图按正负着色——颜色的规则与邮件一致，从屏幕到收件箱不需要重新学习。

## 合上电脑，记录仍在继续

- 新增云端只读页面：把私有仓库部署到 Streamlit Community Cloud（免费），手机浏览器即可查看持仓，电脑关机也不受影响。
- 云端行情在线优先；当免费的 Yahoo 在云端沉默时，自动回退到 Actions 运行所保存的行情快照，并如实标注快照的日期与非实时提示。
- 可选开启受限云端编辑：用一把只属于你的专用令牌，在云端直接增改关注列表与持仓笔记，写回私有仓库；本地一键拉取，同字段冲突时拒绝保存，绝不覆盖。

## 触发权，交还给你

- 报告设置中新增「调度方式」开关：**GitHub 自带定时** 或 **cron-job.org 外部触发**，本地保存或云端直接修改均可。
- 两种自动路径严格互斥，且切换采用两阶段提交——外部任务同步成功之后，新的调度方式才会写入配置；同步失败则一切保持原状，绝无「外部未就绪、原生已停摆」的空窗。
- 原生模式下，盘中与收盘的时间与星期编辑被锁定（GitHub 槽位本就固定），周报月报的自动发送明确标注需要外部触发——界面不再许下它兑现不了的诺言。
- 旧的仓库变量 `STOCKWATCH_SCHEDULER` 退役，可从仓库设置中删除。

## 顺手修好的细节

- 周报 / 月报的汇丰同步失败通知，主题、JSON 与附件名保持真实报告模式，不再误标为收盘日报。
- 调度方式的解析兼容带引号的 YAML 写法，合法配置不再被误判。
- 纯文档提交不再触发完整 CI 测试，把运行时间留给真正改动的代码。
- README 与中文使用说明全面重写：只收邮件的用户全程不需要本地命令，从建仓库到收到第一封日报，五步走完。

## 升级与配置

- `config.yaml` 新增可选的 `scheduler:` 段，缺省为原生定时，旧配置无需改动即兼容。
- 启用外部触发前，请先在 cron-job.org 创建一条模板任务（流程见文档）；切换由工作流两阶段完成，本地保存后会自动排队同步，请到 Actions 确认 `Apply report schedules` 的结果。
- 更新代码后请重启本地 Dashboard；云端部署按文档执行，免费实例内存约 1 GB，闲置一周会休眠，访问即唤醒。
- 邮件中新增的题词与里程碑均为事实陈述或原创短句，不构成投资建议。

## 验证与限制

发布前的回归基线为 305 项离线测试（假行情、假 SMTP、临时 Git 仓库），公开仓库 CI 继续验证运行时与发布扫描。

依旧只是日频近似：不含现金账户、股息、税务与公司行动，基准为价格回报。免费行情可能延迟或缺失，GitHub 与 cron-job.org 都不承诺精确投递；SMTP 与 Git 并非原子事务。免费云端托管资源有限，也不保证共享出口上的行情始终可达。

安装、Gmail、云端部署与自动化配置见 [README](../../README.md)、[中文使用说明](../../使用说明.md) 与 [云端文档](cloud-dashboard.md)。
